# 贪吃蛇

经典贪吃蛇游戏，纯 HTML/CSS/JS 实现，零依赖，直接在浏览器中游玩。

## 快速开始

双击 `snake.html` 即可在浏览器中打开，或者用任意 HTTP 服务器：

```bash
npx serve .
```

## 玩法

- 点击 **开始** 按钮启动游戏
- 使用 **方向键 ↑ ↓ ← →** 控制蛇的移动方向
- 吃到红色食物蛇身变长，分数增加
- 撞到墙壁或自己的身体游戏结束
- 点击 **重新开始** 再来一局

## 技术

- HTML5 Canvas 渲染，20×20 格子，500×500 画布
- setInterval 游戏循环（150ms/步）
- 状态机：待开始 → 游戏中 → 游戏结束
- 经典复古绿黑配色
